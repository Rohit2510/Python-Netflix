# Python-Netflix

Netflix Live Data Analysis Project
Welcome to the Netflix Live Data Analysis Project! This repository contains a comprehensive analysis of the Netflix dataset, which includes information about TV shows and movies available on the platform up until 2021. The project leverages powerful Python libraries such as Pandas, Numpy, and Matplotlib to uncover valuable insights and trends in Netflix content.

📊 Project Overview
In this project, I performed various data analysis techniques to explore the Netflix dataset, focusing on:

Content Analysis: Filtering and aggregating data to understand the distribution of genres, release years, and more.
Visualizations: Creating informative bar graphs and charts to highlight key trends and patterns in the data.
Director Contributions: Identifying the Top 10 Directors who have contributed the highest number of TV shows and movies on Netflix.
Data Manipulation: Utilizing advanced data manipulation techniques to extract meaningful insights from the dataset.
🔧 Tools & Technologies
Pandas: For data manipulation and analysis
Numpy: For numerical operations
Matplotlib: For data visualization
Jupyter Notebook: For interactive data analysis and visualization
📈 Key Takeaways
Gained a deeper understanding of trends in Netflix content.
Uncovered insights into content creation, genre popularity, and director contributions.
Enhanced practical skills in using Python libraries for real-world data analysis.
📁 Dataset
The dataset used for this project was sourced from Kaggle and is included in this repository.
